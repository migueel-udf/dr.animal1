# Sistema de Cadastro em PHP

Projeto desenvolvido em PHP com foco em cadastro e gerenciamento de dados, utilizando integração com banco de dados e estrutura organizada para aplicações web.

---

# 🚀 Tecnologias Utilizadas

* PHP
* HTML5
* CSS3
* MySQL
* XAMPP/WAMP
* Git & GitHub

---

# 📌 Funcionalidades

* Cadastro de usuários
* Listagem de dados
* Edição de registros
* Exclusão de registros
* Integração com banco de dados MySQL
* Interface web simples e funcional

---

# 📂 Estrutura do Projeto

```bash
projeto_php/
│── conexao.php
│── index.php
│── cadastro.php
│── editar.php
│── excluir.php
│── style.css
└── banco.sql
```

---

# ⚙️ Como Executar o Projeto

## 1. Clone o repositório

```bash
git clone https://github.com/migueel-udf/projeto_php.git
```

## 2. Coloque a pasta no servidor local

* XAMPP → `htdocs`
* WAMP → `www`

## 3. Crie o banco de dados

Abra o phpMyAdmin e crie um banco de dados.

## 4. Importe o banco.sql

Importe o arquivo `banco.sql` no banco criado.

## 5. Configure a conexão

Edite o arquivo:

```php
conexao.php
```

com seus dados do MySQL.

## 6. Inicie o Apache e MySQL

Utilize o painel do XAMPP/WAMP.

## 7. Acesse no navegador

```bash
http://localhost/projeto_php
```
